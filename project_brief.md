# My agent: FreelanceLeadMatch
One-liner: A conversational agent that helps freelancers qualify potential clients, recommend tailored service packages, and estimate project scope and pricing.

Tool coverage:
- Memory: Remembers the prospect's project requirements, timeline, budget range, preferred tech stack, and communication history across sessions.
- Tools: Look up freelancer service packages/availability, log qualified client leads into CRM/sheet, and schedule an intro call.
- Catalog/UI: Catalog of freelancer service packages, portfolio case studies, and tier deliverables rendered as interactive A2UI cards/tables.
- Image gen: Generates a personalized project roadmap preview or welcome/quote badge for the client.
- Sandbox: Computes project cost estimates, timeline projections, or ROI calculations based on hours and scope.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for scope/cost estimation, integration with Google Calendar/Sheets API
